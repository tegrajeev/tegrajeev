## About Me

<img align="right" width="40%" src="https://user-images.githubusercontent.com/74038190/212257468-1e9a91f1-b626-4baa-b15d-5c385dfa7ed2.gif" />

I'm a **Full-Stack Software Engineer** currently working as a **Senior Software Developer at Healthworks AI**, building enterprise-grade healthcare data platforms and applied AI systems. My work spans **React/TypeScript frontends, NestJS/Node.js backends, and SQL Server-driven data platforms**, with a growing focus on **generative AI, LLM integration, and AI governance**.

I'm currently building **PromptGate**, an enterprise AI Gateway that sits between internal applications and LLM providers (OpenAI, Claude, Gemini, Azure OpenAI, Ollama) to enforce prompt security, DLP scanning, audit logging, and cost governance — solving a real problem enterprises face when adopting generative AI safely.

On the healthcare side, I design and optimize large-scale provider network intelligence systems — comparing Medicare plans and provider networks across datasets exceeding 1TB and 100+ SQL Server tables. I also bring a strong QA and test-automation background (Playwright, Selenium, JMeter), which shapes how I build: reliable, testable, and production-hardened from day one.

<br/>

An enterprise AI Gateway that sits between enterprise applications and Large Language Models (OpenAI, Claude, Gemini, Azure OpenAI, Ollama) to provide AI governance, prompt security, audit logging, policy enforcement, DLP scanning, and cost analytics.

| Aspect | Details |
|---|---|
| **Stack** | React, TypeScript, Vite, Tailwind CSS, shadcn/ui, NestJS, Node.js, PostgreSQL, Prisma, Docker, GitHub Actions, JWT |
| **Scale** | Unified gateway across 5 LLM providers (OpenAI, Claude, Gemini, Azure OpenAI, Ollama) |
| **Performance** | Centralized routing layer with API key management and usage dashboards |
| **Security** | Prompt Policy Engine, Risk Scanner, DLP scanning, RBAC, enterprise authentication, audit logs |
| **Impact** | Enables secure enterprise AI adoption, prevents sensitive data leakage to LLMs, centralizes AI governance, reduces compliance risk |
| **Repository** | [github.com/tegrajeev/promptgate](https://github.com/tegrajeev/promptgate) |

Key features include a Prompt Optimizer, Cost Analytics dashboard, Role-Based Access Control, and a unified API abstraction so enterprise applications can switch between LLM providers without code changes — while every request is policy-checked and logged.
